# 记账本 APP（类似“随手记”）- 产品需求文档（PRD）

## 1. 产品愿景
帮助个人与家庭轻松、精细、长期地管理收支，支持灵活账期与强大统计，以数据驱动财务健康与目标达成。

## 2. 用户与场景
- 目标用户：个人用户、家庭共同记账用户、小微个体户。
- 主要场景：
  - 日常随手记：打开即记一笔，支持语音、拍照识别。
  - 预算与提醒：为每月（或自定义账期）设定预算并异常提醒。
  - 报表洞察：按分类、时间、商家、标签、账户维度查看月度/年度报表与趋势。
  - 多账户管理：现金、银行卡、信用卡、电子钱包、投资账户等。
  - 家庭共享：多人共用一个账本，权限可控（扩展）。

## 3. 目标与衡量（KPI）
- 7天留存 > 35%，30天留存 > 18%。
- 记账频率：人均每日记账 ≥ 1.5 笔。
- 首笔记账用时（TTB）：≤ 30 秒。
- 报表使用率：月度 ≥ 50%，年度 ≥ 30%。
- 错账率：编辑/删除比例 ≤ 3%。

## 4. 范围与版本规划（调整为本地优先 MVP）
- V1（本地 MVP）：
  1) 支出/收入分类记账（含自定义分类与图标）
  2) 自定义月度记账开始日（账期起点）
  3) 月度/年度统计报表（按分类、账户、标签维度）
  4) 多账户与转账（转账不计入收支）
  5) 标签、备注、图片附件；商家/地点（可选）
  6) 预算与提醒（按账期、按分类预算，本地通知）
  7) 数据导入/导出（CSV）
  8) 本地加密存储与备份/恢复
- V1.1+（扩展能力，保留云端同步）：
  - 云端同步与备份（账号体系、冲突合并）
  - 家庭共享与成员权限
  - OCR/票据识别、语音输入、自动化规则
  - 资产负债视图、净值趋势、目标储蓄
  - 投资账户收益对接

## 5. 需求明细与验收标准
### 5.1 记一笔
- 需求：
  - 类型：支出/收入/转账
  - 金额：> 0；两位小数
  - 分类：必选（自定义支持层级 ≤ 2 级）
  - 账户：必选；转账需双账户
  - 时间：默认当前时间，可修改
  - 标签：0..N；备注：0..500字
  - 附件图片：0..9（选）
- 验收：
  - ≤ 3 步完成一笔（默认记忆上次分类/账户）
  - 表单校验完整，离线可记，本地持久化；后续可选云同步

### 5.2 分类管理
- 需求：默认分类模板；可增删改、排序、设图标/颜色；支持多级（≤2级）。
- 验收：分类变更不影响历史记录展示（保留历史引用）。

### 5.3 多账户与转账
- 需求：账户类型（现金/借记卡/信用卡/电子钱包/储值卡/虚拟账户等）；转账不计入收支，仅影响余额；账户初始余额与调整。
- 验收：余额计算正确；转账为双向原子操作。

### 5.4 自定义账期（创新重点）
- 需求：账本级设定“月度起始日”（1..28）；所有“月度报表/预算/提醒”按账期计算。
- 验收：跨月边界计算正确（含2月与大小月）。

### 5.5 预算与提醒
- 需求：支持总预算与分类预算；阈值提醒（70%/100%）；预算以账期对齐；本地通知。
- 验收：到达阈值及时通知；报表显示执行率。

### 5.6 报表与统计
- 需求：
  - 维度：分类/时间/账户/标签/商家
  - 粒度：按账期的月度、自然年度（可选账期年）
  - 展示：饼图、柱状图、趋势线；可导出CSV
- 验收：统计可追溯到明细；本地计算 < 300ms/请求。

### 5.7 数据导入/导出
- CSV模板下载；导入字段校验与映射；导出按筛选条件。

### 5.8 隐私与安全
- 本地加密（SQLite加密或系统安全区）；本地备份/恢复。
- 云端加密传输与存储（扩展能力，非 MVP）。

### 5.9 无障碍与国际化
- 动态字体、深色模式、VoiceOver/TalkBack；多语言（简中首发，后续英/繁）。

## 6. 信息架构（简）
- 底部导航：记一笔｜报表｜账户｜我
- 快捷入口：长按桌面图标、通知快捷记账、Widget
- 记一笔页：金额（大号）→ 类型 → 分类 → 账户 → 标签/备注/照片

## 7. 里程碑（本地 MVP 优先）
- PRD冻结：T0+3d；设计走查：T0+7d；开发完成（本地MVP）：T0+30d；小范围发布：T0+35d；云同步方案设计评审：T0+45d（可选）。

## 8. 非功能
- 性能：主流程反馈 < 100ms；崩溃率 < 0.3%；兼容：iOS 14+/Android 8+。
- 本地优先：所有核心功能在离线可用；网络仅用于未来扩展。

## 9. 风险与对策
- 数据丢失：本地备份/恢复；扩展后提供云备份与冲突合并策略。
- 学习成本：默认模板、上手引导、空状态示例。
- 隐私合规：本地数据最小化；扩展云同步时遵从GDPR/本地法规。

## 10. 创新功能（初版）
- 智能账期引擎：根据消费周期建议账期起点。
- AI 分类纠错与自动标签：识别备注/商家自动归类。
- 语音快速记账：离线关键词解析。
- 规则自动化：解析短信/支付通知自动入账（需授权）。
- 反思卡片：每周/每月自动生成消费洞察与建议。
- 现金流预测：基于历史与预算预测未来30天可支配。
- 家庭账本分摊：AA/权重分摊，结算协作（扩展）。
